## Hardware Prototype Progress

The first hardware prototype of the ESP32 access-control system is now operational.

Current features:
- ESP32 microcontroller
- 4x4 matrix keypad for user input
- SSD1306 OLED display using I2C
- Buzzer for audio feedback
- User-defined access code
- Access Granted / Access Denied feedback
- Ability to change the access code
